Help

  1. Enter a public website URL (for example https://example.com).
  2. Click Analyze Website.

Troubleshooting

  • Could not connect – check the address and your internet connection.
  • Only public websites – localhost and private network addresses are blocked.
  • Not HTML – the URL must point to a web page, not a file.
